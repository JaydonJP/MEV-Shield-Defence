FIRST TIME USING A WALLET?

Set up a wallet for this demo

No Ethereum wallet was detected in this browser. Connecting opens a request in your wallet extension; it doesn’t create a wallet for you.

  1. Install MetaMask in your browser

    Use Chrome, Edge, Firefox, or another supported browser. An embedded app browser may not have access to your extensions.

    Get MetaMask from the official website ↗
  2. Create a separate demo wallet

    Choose “Create a new wallet” and complete MetaMask’s setup. Keep your password and recovery phrase private; this website never needs them.

    Official wallet creation instructions ↗
  3. Open this website in that same browser

    Reload the page, unlock MetaMask, click Connect wallet, and approve the account and Sepolia network requests. Connecting itself needs no ETH.

  4. Get free test ETH when you’re ready to deploy

    Use a Sepolia faucet, then return to Live blockchain → Deploy ShieldVault. Use test ETH for this demo.

    Sepolia testnet and faucet resources ↗
The attack lab and live block feed also work without a wallet.
